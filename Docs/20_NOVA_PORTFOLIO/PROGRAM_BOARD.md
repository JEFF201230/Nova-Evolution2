# PROGRAM BOARD

## Board Name

NOVA Program Board

## Status

ACTIVE

## Purpose

The NOVA Program Board governs the complete NOVA Operating System portfolio.

## Responsibilities

- Approve new Programs.
- Prioritize Programs.
- Allocate Delivery Squads.
- Validate Program completion.
- Approve Mission Orders.
- Review Campaign results.
- Manage portfolio risks.
- Maintain the global roadmap.

## Decision Values

- APPROVED
- REJECTED
- DEFERRED
- ESCALATED

## Authority

The Program Board is the only authority allowed to:

- move a Program from PLANNED to ACTIVE;
- declare a Program COMPLETE;
- authorize the creation of a new Program;
- authorize the closure of a Program.

## Governance Rules

No Program may start without Program Board approval.

No Mission Order may be issued outside an ACTIVE Program.

No Campaign may be opened outside an approved Mission Order.
