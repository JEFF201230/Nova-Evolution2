\# Migration Policy



KEEP

Le document reste exclusivement dans VEEDDA.



COPY

Le document est dupliqué dans NOVA.



MIGRATE

Le document devient une référence officielle de NOVA tout en conservant une copie historique dans VEEDDA.



HOLD

Décision suspendue jusqu'à audit.



SHARED

Le document est partagé entre les deux plateformes.
