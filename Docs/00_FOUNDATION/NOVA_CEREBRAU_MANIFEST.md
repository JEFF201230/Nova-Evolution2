Il est la porte d'entrée unique de la documentation NOVA.

\# Foundation Documents



Les documents Foundation définissent les règles permanentes de NOVA.



Ils ne peuvent être modifiés qu'après validation Executive.



Ils constituent la Source of Truth.



\---



\# Architecture Documents



Ils décrivent la conception fonctionnelle et technique.



Ils sont utilisés par les agents de développement.



\---



\# Runtime Documents



Ils définissent le comportement du système.



Ils constituent le contrat fonctionnel du Runtime.



\---



\# Reference Documents



Ils regroupent :



\- index

\- dictionnaires

\- catalogues

\- nomenclatures

\- références canoniques



\---



\# Incubation
