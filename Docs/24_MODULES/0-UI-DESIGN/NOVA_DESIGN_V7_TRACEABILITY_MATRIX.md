## 1. Règles de lecture

- Les identifiants `W01.x`, `G01`, `D01` et `D02.x` viennent de `NOVA_USER_NAVIGATION_ARCHITECTURE.md`.
- Les identifiants `Txxx` viennent de `NOVA_NAVIGATION_MATRIX.md`.
- Les capabilities et statuts viennent de `NOVA_CAPABILITY_REGISTRY.md` et `NOVA_PLATFORM_ACTIVATION_MATRIX.md`.
- `NONE` est l'absence explicite constatée dans la matrice SW-005.
- Un filtre, un drawer, une étape ou un disclosure n'est pas promu en capability autonome.
- La planche annotée `NOVA-GLOBAL-DECISIONS-REFERENCE-V7.png` est rattachée à `G01` comme référence, mais n'est pas comptée comme capture produit Pixel Perfect.
- Les exports annotés de `v7/screens/` sont des écrans de référence sémantiques ; ils ne prouvent pas tous les états ou interactions.
- `O01` est rattaché à `SEARCH-OVERLAY/search-overlay.png` par SW-007F ; aucune Capability UI autonome Search n'est enregistrée.
