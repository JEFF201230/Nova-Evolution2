## Regles communes

- un agent agit uniquement dans le perimetre de sa mission ;
- un agent produit un livrable explicite et verifiable ;
- un agent signale les hypotheses, risques et blocages ;
- un agent ne modifie pas les priorites, la gouvernance ou l'architecture sans autorisation ;
- un agent s'arrete des qu'un critere d'arret est atteint.
