Ce document définit le contrat minimal qu'un projet doit respecter pour être

déclaré \*\*Projet de Référence\*\* dans la bibliothèque de savoir-faire.

`PROJECT\_REFERENCE\_REGISTRY.md`



que si ce manifeste est entièrement renseigné et validé.
