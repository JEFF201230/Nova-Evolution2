# PROGRAM DELIVERY SQUAD STANDARD

## Identifier

PDS-001

## Name

Program Delivery Squad

## Purpose

Execute one approved Program from PLANNED or ACTIVE to COMPLETE while respecting NOVA governance.

## Responsibilities

The Program Delivery Squad may produce:

- Program Charter
- Program Index
- Roadmap
- Governance documents
- Mission Orders
- Campaign plans
- Execution reports
- Verification reports
- Certification reports
- Result reports
- Program closure package

## Mandatory Workflow

1. Read Program approval.
2. Verify Program Board authorization.
3. Read or create Program Charter.
4. Read or create Program Index.
5. Build Program Roadmap.
6. Issue required Mission Orders.
7. Open Campaigns.
8. Delegate implementation to Mission or Campaign Delivery Squads.
9. Execute tests.
10. Produce evidence.
11. Execute verification.
12. Execute certification.
13. Close all Mission Orders.
14. Close the Program.

## Reporting Obligations

After each Mission Order, report:

- Program status
- Mission Orders completed
- Mission Orders in progress
- Mission Orders remaining
- Campaign status
- Progress percentage
- Files created
- Files modified
- Tests executed
- PASS
- FAIL
- Coverage
- Decision

## Decision Values

- CONTINUE
- GO
- REWORK
- STOP
- ESCALATE

## Resume Rule

If interrupted, the squad must reread:

- Portfolio
- Program documents
- Mission Orders
- Campaign reports
- Evidence
- Certification reports

Then resume from the last verified GO state.

## Exit Criteria

A Program may be declared COMPLETE only when:

- all Mission Orders are COMPLETE;
- all Campaigns are CLOSED;
- all required tests are PASS;
- all certifications are GO;
- all required reports are produced;
- Program Board closure is approved.

## Restrictions

The Program Delivery Squad shall never:

- modify another Program without authorization;
- modify certified Runtime components;
- modify certified Kernel components;
- modify closed Mission Orders;
- skip a validation gate;
- delete evidence;
- declare a Program COMPLETE without proof.
