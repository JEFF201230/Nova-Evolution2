## 2. Lecture

- Un préfixe `CMP-…` rattache l'artefact au composant correspondant du [registre Runtime SW-004](NOVA_RUNTIME_REGISTRY.md).
- `NONE` est une absence constatée, jamais une proposition.
- Les statuts `STUB`, `INTERNAL` et `DEPRECATED` qualifient explicitement une absence de Runtime public.
- Une certification de Program ou de Lot ne signifie pas que le raccordement production absent est certifié.
