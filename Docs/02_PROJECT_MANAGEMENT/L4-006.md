# LOT L4-006

Version : 1.0

Statut : LIVRE

---

# 1. Identification du lot

Identifiant du lot : L4-006

Titre du lot : Knowledge Center connecte a CEREBRAU

Autorite emettrice : Product Owner

Executant : Codex

Document de reference obligatoire : MASTER_EXECUTION_SPECIFICATION v1.0

---

# 2. Objectif

Objectif unique du lot :

Mettre en place un Knowledge Center applicatif connecte directement au CEREBRAU Context Engine pour consulter, rechercher et exposer les decisions, RFC, baselines, references legacy et l'etat de contexte reconstruit.

---

# 3. Contexte

Contexte fourni :

- Connexion directe avec CEREBRAU.
- Recherche.
- Decisions.
- RFC.
- Baselines.
- Legacy.
- Context Engine.

References autorisees :

- `server/cerebrau-context/`
- `Docs/09_CEREBRAU OPERATING SYSTEM/02_PROJECT_MANAGEMENT/DECISION_REGISTER.md`
- `Docs/09_CEREBRAU OPERATING SYSTEM/06_REFERENCE/`
- `Docs/09_CEREBRAU OPERATING SYSTEM/05_RULES/KNOWLEDGE_GOVERNANCE.md`

---

# 4. Perimetre autorise

Actions autorisees :

- exposer une API de lecture vers le CEREBRAU Context Engine ;
- creer une page Knowledge Center dans le module GDBCSE ;
- ajouter une recherche locale sur les surfaces Knowledge reconstruites ;
- synchroniser le registre de lot.

Fichiers autorises en modification :

- `server/routes.ts`
- `client/src/gdbcse/layouts/GdbcseLayout.tsx`
- `client/src/gdbcse/components/HeaderGdbcse.tsx`
- `client/src/gdbcse/styles/gdbcse-layout.css`
- `Docs/09_CEREBRAU OPERATING SYSTEM/02_PROJECT_MANAGEMENT/LOT_REGISTER.md`

Fichiers autorises en creation :

- `client/src/gdbcse/pages/GdbcseKnowledgeCenter.tsx`
- `Docs/09_CEREBRAU OPERATING SYSTEM/02_PROJECT_MANAGEMENT/L4-006.md`

---

# 5. Perimetre interdit

Actions interdites :

- modifier les donnees CEREBRAU depuis le Knowledge Center ;
- remplacer le Context Engine ;
- creer un moteur de recherche externe ;
- modifier les decisions, RFC, baselines ou documents legacy sources ;
- executer une migration ou un commit.

---

# 6. Livrables

Livrables obligatoires :

- endpoint `GET /api/cerebrau/knowledge-center` ;
- page `GdbcseKnowledgeCenter` ;
- entree de navigation GDBCSE `Knowledge` ;
- fiche de lot `L4-006.md` ;
- entree `L4-006` dans `LOT_REGISTER.md`.

---

# 7. Criteres d'acceptation

- Le Knowledge Center consomme le Context Engine en lecture seule.
- La page expose les blocs Recherche, Decisions, RFC, Baselines, Legacy et Context Engine.
- La recherche filtre localement les surfaces restituees.
- L'acces backend est reserve aux roles CSE autorises.
- Le lot est tracable dans le registre NOVA ORCHESTRATOR.
