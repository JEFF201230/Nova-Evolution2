# CHANGE CERTIFICATION

## Purpose

Certify that a change is ready for controlled execution.

## Certification Criteria

- Scope validated
- Risk classified
- Human approval recorded
- Commit plan defined
- Rollback plan defined
- Evidence package complete

## Certification Outcomes

- Certified
- Certified with reservations
- Not certified

## Evidence

- Validation record
- Approval record
- Plan record
- Rollback record
- Certification record

## Decision

Change certification defined.
