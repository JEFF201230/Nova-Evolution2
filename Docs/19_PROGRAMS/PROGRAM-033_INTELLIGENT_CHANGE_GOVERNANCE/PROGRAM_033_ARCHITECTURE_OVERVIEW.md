# PROGRAM-033 - ARCHITECTURE OVERVIEW

## Status

FOUNDATION DOCUMENT.

## Principle

L'IA prepare, l'humain decide, NOVA execute.

## Architecture Flow

```text
Change Signal
-> Decision Intelligence
-> Change Classification
-> Mission Scope Validation
-> Commit Planning
-> Human Decision Workflow
-> Rollback Governance
-> Change Certification
```

## Decision Layers

- L0 automation gathers evidence.
- L1 AI analyzes, classifies, and recommends.
- L2 human validates and decides.
- L3 NOVA executes only after authorization.

## Validation Points

- Scope validation before planning
- Human validation before execution
- Certification validation before closure

## Blocking Rules

- Block if scope is ambiguous.
- Block if evidence is incomplete.
- Block if rollback cannot be proven.
- Block if human approval is missing.

## Reopen Rules

- Reopen when new evidence resolves the block.
- Reopen when human authorization changes the decision.
- Reopen when the rollback path becomes valid.

## Evidence

- Input evidence
- Classification evidence
- Decision evidence
- Rollback evidence
- Certification evidence

## Decision

Architecture overview established.
