# ROLLBACK GOVERNANCE

## Purpose

Define how NOVA stops, reverts, or recovers from a change.

## Rules

- Rollback must be designed before execution.
- Rollback must be testable in principle.
- Rollback must be approved with the change.
- Rollback must preserve evidence.

## Blocking Criteria

- No rollback path
- Rollback path not understood
- Rollback path exceeds authority
- Rollback path cannot be certified

## Reopen Criteria

- A valid rollback path is produced
- Human review accepts the rollback plan
- Evidence confirms recovery feasibility

## Decision
