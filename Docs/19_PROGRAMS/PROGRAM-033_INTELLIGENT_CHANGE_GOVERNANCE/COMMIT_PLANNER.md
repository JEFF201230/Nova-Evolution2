# COMMIT PLANNER

## Purpose

Prepare an authorized change for execution.

## Planning Rules

- Plan only after scope validation.
- Plan must include ordering and dependency resolution.
- Plan must include rollback and stop conditions.
- Plan must be reviewable by a human.

## Outputs

- Commit sequence
- Dependency order
- Validation checkpoints
- Rollback path
- Execution readiness summary

## Decision

Commit planning defined.
