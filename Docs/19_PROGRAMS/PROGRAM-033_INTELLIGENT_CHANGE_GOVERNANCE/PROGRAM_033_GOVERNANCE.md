# PROGRAM-033 - GOVERNANCE

## Authority

PROGRAM-033 is governed by the NOVA Program Board and must remain consistent with certified NOVA baselines.

## Governance Principles

- AI prepares change analysis and recommendations.
- Humans approve, reject, defer, or escalate decisions.
- NOVA executes only after authorized decision gates.
- No silent change on mission-critical paths.
- Every decision must be evidence-backed.

## Decision Levels

| Level | Actor | Authority |
| --- | --- | --- |
| L0 | Automation | Collect evidence, classify change, draft plan |
| L1 | AI | Recommend scope, risk, impact, rollback, and certification posture |
| L2 | Human | Validate, approve, block, or request revision |
| L3 | Program Board | Authorize policy, scope, release, and exceptional escalation |

## Validation Gates

- Mission scope validation
- Change classification validation
- Commit plan validation
- Rollback validation
- Human approval validation
- Certification validation

## Blocking Criteria

- Scope ambiguity
- Insufficient evidence
- High-risk dependency conflict
- Policy violation
- Unauthorized execution path

## Reopen Criteria

- New evidence resolves the block
- Scope is clarified by an authorized human
- Risk is reduced below threshold
- Rollback plan becomes executable and reviewed

## Evidence Required

- Scope summary
- Impact analysis
- Dependency analysis
- Risk classification
- Human decision record
- Certification record

## Decision

Governance established.
