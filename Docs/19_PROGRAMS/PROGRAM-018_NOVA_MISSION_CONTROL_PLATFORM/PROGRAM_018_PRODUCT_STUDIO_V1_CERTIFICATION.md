## 5. Certification Boundary

This certification authorizes:

- professional high-fidelity design in Figma;
- construction of the specified component library in Figma;
- assembly of the specified interactive prototype;
- inclusive usability testing;
- developer handoff refinement.

This certification does not authorize:

- React implementation;
- production release;
- claims of implemented WCAG conformance;
- autonomous critical decisions;
- modification of certified baselines;
- portfolio-wide certification of NOVA-CMEP-001.

## 6. Residual Obligations

The following non-blocking obligations transfer to Figma production:

- create all required frames, variants and responsive key screens;
- apply exact or documented successor tokens;
- attach accessibility annotations;
- prototype all required flows and adverse states;
- test with representative populations, including access-needs users and VEEDDA roles;
- record material deviations and corrections;
- re-run accessibility and technical-readiness review before implementation authorization.
