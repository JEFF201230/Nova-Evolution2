# Modèle Économique NOVA V2

## Statut du document

STRATÉGIE APPROUVÉE.

## Thèse Commerciale

NOVA doit monétiser l’exécution IA gouvernée, pas l’accès brut aux modèles. Les acheteurs paieront pour la responsabilité, la vitesse, les preuves, l’auditabilité, le contrôle des coûts et l’intégration dans le travail d’entreprise.

## Modèle de Prix

La tarification recommandée combine abonnement plateforme, usage et services.

| Composant | Logique de tarification | Rationale |
| --- | --- | --- |
| Abonnement plateforme | Abonnement annuel récurrent par édition | Revenu prévisible |
| Postes opérateur | Utilisateurs nommés pour la gouvernance et le contrôle d’exécution | Achat familier |
| Capacité agent | Packs d’agents actifs ou d’heures agent | Alignement avec la valeur de résultat |
| Usage IA | Refacturation à l’identique plus marge ou allocation incluse | Contrôle de l’exposition au coût |
| Packs d’intégration | Par produit ou système intégré | Monétise la valeur d’implémentation |
| Contrôles entreprise | Premium pour SSO, tenancy, audit, déploiement | Disposition à payer des entreprises |
| Certification | Services de certification payants et package de conformité récurrent | Différenciateur |
| Marketplace | Partage de revenu sur les extensions certifiées | Marge écosystème de long terme |

## Bandes de Prix Suggérées

| Édition | Prix annuel | Cible |
| --- | ---: | --- |
| Pilot | USD 25K-75K | Design partner, périmètre limité |
| Team | USD 60K-150K | Petite équipe entreprise |
| Enterprise | USD 180K-500K | Organisation multi-équipes |
| Regulated Enterprise | USD 500K-1.5M+ | On-prem, contrôles, certification |
| Integration Pack | USD 25K-250K | Par produit/système |

La tarification finale doit être validée par la découverte auprès des design partners.

## Licensing

La licence doit supporter :

- l’abonnement SaaS ;
- le private cloud ;
- le déploiement on-prem ;
- la licence OEM ;
- la licence white-label ;
- les conditions partenaires de marketplace ;
- les contrats de certification et de formation.

Dimensions de licence :

- tenants ;
- environnements ;
- Programs actifs ;
- missions mensuelles ;
- agents actifs ;
- appels API ;
- dépense modèle ;
- stockage et rétention ;
- package de conformité.

## Offre Entreprise

Les acheteurs entreprise requièrent :

- SSO et RBAC ;
- isolation des tenants ;
- traces d’audit ;
- contrôles de rétention des données ;
- options de déploiement ;
- documentation d’achat ;
- package de revue sécurité ;
- SLA support ;
- export de preuves ;
- reporting du coût d’usage modèle ;
- approbation humaine et gestion des exceptions.

## Offre Cloud

Le cloud doit être le choix par défaut pour le premier revenu :

- onboarding plus rapide ;
- friction d’implémentation réduite ;
- télémétrie et support plus simples ;
- pilotes plus faciles.

Le cloud doit néanmoins continuer à supporter des politiques fournisseur spécifiques au client et des contrôles de données stricts.

## Marketplace

Le revenu marketplace doit être introduit après maturité de la plateforme de plugins.

Options de revenu :

- 20 à 30 % de partage de revenu sur les plugins payants ;
- frais de certification ;
- placement partenaire sponsorisé ;
- abonnements d’intégration managée ;
- packs de templates.

La marketplace ne doit pas entrer dans les prévisions de revenu de la première version.

## Certification

La certification peut devenir une offre à forte marge, car NOVA possède déjà un fort ADN de preuves et de gouvernance.

Produits de certification :

- package de certification de release ;
- certification de gouvernance IA ;
- audit d’exécution de mission ;
- certification de plugin ;
- certification d’intégration ;
- rapport de conformité spécifique client.

## Consulting

Le consulting est nécessaire pour l’adoption initiale mais ne doit pas devenir le cœur du business.

Services :

- évaluation d’implémentation ;
- conception du modèle opératoire de mission ;
- mise en place d’intégration ;
- configuration de la gouvernance IA ;
- mise en place de prompts et de packages d’évaluation ;
- migration depuis les workflows existants ;
- habilitation des dirigeants.

## Formation

Produits de formation :

- NOVA Operator ;
- NOVA Program Board ;
- NOVA Mission Designer ;
- NOVA Agent Governance ;
- NOVA Integration Developer ;
- NOVA Auditor.

La formation soutient l’adoption et réduit la charge support.

## OEM et White Label

Opportunités OEM et white-label :

- cabinets de conseil intégrant l’exécution IA gouvernée ;
- éditeurs sectoriels ajoutant l’orchestration IA ;
- intégrateurs de systèmes packagant NOVA avec des offres de transformation ;
- plateformes de secteurs régulés ayant besoin de preuves et de gouvernance IA.

Le white-label doit être différé jusqu’à ce que les API produit, le déploiement et les opérations support soient matures.

| Segment | Pourquoi il correspond |
| --- | --- |

## Décision de Modèle Économique

NOVA doit vendre une plateforme par abonnement avec économie IA sensible à l’usage, contrôles entreprise payants, packs d’intégration, certification et services sélectifs. Le modèle doit éviter une dépendance pure aux sièges et s’aligner progressivement sur le résultat, la capacité agent et le volume d’exécution gouvernée.
