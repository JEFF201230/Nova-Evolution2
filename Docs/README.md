# CEREBRAU Operating System

## Mission

CEREBRAU Operating System est l'espace documentaire de reference pour organiser, piloter et gouverner les travaux CEREBRAU.

Il centralise les documents utiles a la coordination des lots, a la gestion des agents, a la description des workflows, aux regles de fonctionnement, aux references communes et aux archives.

## Positionnement dans CEREBRAU

CEREBRAU Operating System se situe au niveau de pilotage du projet CEREBRAU.

Il ne remplace pas les modules metiers de CEREBRAU.

Il fournit un cadre documentaire permettant de relier les decisions, les lots, les workflows et les references communes dans un espace unique.

## Perimetre

Le perimetre de CEREBRAU Operating System couvre :

- la documentation coeur du systeme ;
- la gestion des lots et du suivi projet ;
- la description des agents ;
- la description des workflows ;
- les regles et references communes ;
- l'archivage des documents historiques.

Le perimetre ne couvre pas :

- le code applicatif ;
- les migrations ;
- les secrets ;
- les documents metiers externes au dossier CEREBRAU Operating System.

## Organisation generale

L'organisation documentaire est structuree comme suit :

- `01_CORE` : documents coeur du systeme ;
- `02_PROJECT_MANAGEMENT` : documents de lots et suivi projet ;
- `03_AGENTS` : documents relatifs aux agents ;
- `04_WORKFLOWS` : workflows de travail ;
- `05_RULES` : regles communes ;
- `06_REFERENCE` : references transverses ;
- `99_ARCHIVES` : archives.

## Documents de gouvernance

Les principaux documents de gouvernance sont :

- `MASTER_EXECUTION_SPECIFICATION.md` ;
- `LOT_TEMPLATE.md`.

`MASTER_EXECUTION_SPECIFICATION.md` porte les regles d'execution.

`LOT_TEMPLATE.md` porte le modele officiel des lots.
